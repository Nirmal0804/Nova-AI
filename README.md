# Nova-AI

Multimodal AI for Earth Observation. From raw satellite imagery to clear insight.

## Frontend Tech Stack

This project's frontend is built with modern, high-performance web technologies:

### Core Frameworks
* **[React 19](https://react.dev/)**: The core UI library.
* **[TypeScript](https://www.typescriptlang.org/)**: For robust, statically typed code.
* **[TanStack Start](https://tanstack.com/start/latest) & [Router](https://tanstack.com/router/latest)**: For full-stack React framework capabilities and type-safe routing.
* **[Vite](https://vitejs.dev/)**: For lightning-fast local development and optimized production builds.

### State & Data Management
* **[TanStack Query](https://tanstack.com/query/latest)**: For declarative data fetching, caching, and state management.
* **[React Hook Form](https://react-hook-form.com/) & [Zod](https://zod.dev/)**: For form handling and schema validation.

### Styling & Animation
* **[Tailwind CSS v4](https://tailwindcss.com/)**: Utility-first CSS framework for rapid styling.
* **[Framer Motion](https://www.framer.com/motion/)**: For smooth, declarative layout animations and gestures.
* **Vanilla CSS**: Deeply customized design system using modern `oklch()` color spaces.

### UI Components
* **[Radix UI](https://www.radix-ui.com/)**: Unstyled, accessible UI primitives.
* **[Lucide React](https://lucide.dev/)**: Beautiful and consistent iconography.
* **[Recharts](https://recharts.org/)**: For data visualization.
* **[React Markdown](https://github.com/remarkjs/react-markdown)**: For rendering assistant chat responses.
